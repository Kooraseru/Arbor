# Examples

Example source fixtures are stored under `src/examples/`.

Each example follows the same shape:

```txt
problem
source
result
why it works
```

Start with serialized type relationships, then move into plugin sandbox and
generated facade examples.

- [Serialized Types](examples/serialized-types.md)
- [Plugin Sandbox](examples/plugin-sandbox.md)
- [Generated Type Facade](examples/generated-type-facade.md)

The examples are source fixtures first and wiki material second. If an included source block changes here, it should also be analyzer-checked in the repository.

The analyzer fixture contract lives in
[Analyzer Fixtures](reference/analyzer-fixtures.md).
