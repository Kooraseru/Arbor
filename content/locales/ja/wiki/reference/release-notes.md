# リリースノート

リリースメタデータとローカライズされた文章が、Arbor のリリース内容についての唯一の基準です。

バージョン、チャンネル、日付、アセットの共通メタデータは、`release-notes/` に TOML で置きます。人が読むセクションは、各ロケールの `release.toml` に置きます。

## メタデータ

```toml
version = "v1.0.1"
channel = "stable"
date = "2026-07-09"
assets = ["Arbor.rbxm"]
```

リリースノートと変更履歴のジェネレーターは、このメタデータを選択したロケールと組み合わせます。ルートの GitHub リリース本文には、`default = true` が指定されたロケールを使います。
